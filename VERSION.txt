PC Medic 1.5.0
Build date: 2026-09-19

Local-first Windows 10/11 diagnostics, hardware inventory, live telemetry,
reporting, and guided Microsoft-tool repairs.

1.0.1: Added a guarded launcher and persistent startup/installation error logs.
1.0.2: Kept the interface responsive during native scans, corrected DISM health
matching, and removed Windows PowerShell 5.1 character-encoding artifacts.
1.1.0: Added a silent launcher, redesigned the interface, and added contextual
issue explanations and one-click repair routing.
1.2.0: Added automatic and manual GitHub Release updates with semantic version
comparison, SHA-256 verification, and in-place installation.
1.2.1: Fixed the DISM output-pipe deadlock and replaced Windows' tab rendering
with a consistent dark custom template.
1.3.0: Added automatic repair-stage navigation, live repair progress, current
activity descriptions, percentages, and clear completion or failure states.
1.4.0: Expanded Windows event-log diagnostics for application crashes, disk
and NTFS faults, driver and service failures, Windows Update errors, Defender
events, and memory-test results, with repeated events grouped by cause.
1.5.0: Added one-click repair of all safely automatable scan findings, with a
restore point, matching Windows repair tools, progress stages, and clear
identification of issues that still require manual review.
